# Existing admin feature inventory

Recorded before the admin extension on 2026-11-01.

- Dashboard: demo gross sales, product count, low-stock and new-enquiry counts, recent orders, stock watchlist, and shortcuts to catalog and homepage builder.
- Homepage builder: enable and reorder homepage sections; create, edit, enable, reorder and delete hero slides; select hero modes, custom copy and images (including uploads, mobile image, focal and text positions), CTA and carousel timing; configure the announcement bar; select featured and deal products; preview storefront and reset homepage configuration.
- Products: search and category filter; add/edit product name, brand, category, SKU, price, stock, image URL and short description; quick stock adjustments; delete products.
- Categories and brands: read-only category/subcategory and brand/series hierarchy.
- Orders: list orders and inspect order details.
- Enquiries: list enquiry details, contact information, budget and status.
- Settings: reset local demo data after confirmation.
- Layout: navigation, storefront preview and customer-view links. Catalog and homepage changes persist in localStorage; homepage configuration is reflected on the storefront.
