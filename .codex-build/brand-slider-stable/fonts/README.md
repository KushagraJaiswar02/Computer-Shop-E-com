# Self-hosted fonts

Inter (400–600) and Space Grotesk (600–700) variable WOFF2 files are the official Google Fonts Latin and Latin Extended subsets, downloaded on 2026-11-02. Latin Extended includes U+20B9 (₹). The original families were also checked directly against their official TTF cmap tables for this glyph.

Sources: https://fonts.google.com/specimen/Inter and https://fonts.google.com/specimen/Space+Grotesk. Licenses are included as inter-OFL.txt and spacegrotesk-OFL.txt. CSS uses font-display: swap. No font package is required. Only the Inter Latin subset is preloaded; the browser requests other subsets as needed.
