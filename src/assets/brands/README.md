# Brand logos

Vendored from [Simple Icons 16.35.0](https://github.com/simple-icons/simple-icons/tree/16.35.0/icons), licensed under [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/16.35.0/LICENSE.md). Brand trademarks remain their owners’ property.

ASUS, Lenovo, MSI, AMD, Intel, Corsair, Samsung and Dell use the original SVG paths. The root fill is `currentColor`; viewBoxes are cropped to the artwork bounds for consistent visual sizing. Dell represents the combined Dell / Alienware tile.

Official hover colors come from the same release’s [metadata](https://github.com/simple-icons/simple-icons/blob/16.35.0/data/simple-icons.json). Lighter dark-mode variants preserve contrast; ASUS and Corsair use near-white.

Raw SVG imports are trusted local assets, inlined so `currentColor` inherits the card’s hover and keyboard-focus color. No runtime requests or icon dependency are required.
